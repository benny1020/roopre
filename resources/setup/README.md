# 루프리 설치·복구 안내 · 0.3.0-beta.1

이 빌드는 macOS 로컬 소유자 베타입니다. Git과 실행 중인 Docker Desktop이 필요합니다. 소스 저장소·Node·pnpm은 앱 실행에 필요하지 않습니다. Developer ID 서명·Apple 공증 여부는 배포 파일의 manifest에서 확인합니다.

## 첫 실행

1. 앱을 Applications 폴더에 복사하고 엽니다. DB가 없어도 시작 가이드가 열립니다.
2. AI 연결에 Anthropic Messages 호환 HTTPS endpoint·model·API key 또는 Bearer를 입력합니다. 저장만으로 모델 요청을 보내지 않습니다. 연결 검사는 소량의 비용이 들 수 있습니다.
3. 환경 준비에서 Git·Docker를 확인하고 **환경 준비**를 누릅니다. 전용 PostgreSQL과 격리 실행 이미지를 준비합니다. 처음에는 네트워크와 수 GB의 공간이 필요할 수 있습니다. 진행 단계·실패·중단·재시도를 앱에서 확인합니다.
4. 내 Git 저장소를 선택하고 기준 브랜치·AI 연결·예산·필수 검사 명령을 확인합니다. 현재 Node 단일 패키지의 npm/pnpm 잠금 파일을 지원합니다.
5. 전역/프로젝트 지침과 단계별 에이전트를 구성합니다. 기본 흐름은 사용자가 적용하는 설정 템플릿이며 가상의 프로젝트/결과를 생성하지 않습니다.
6. 첫 요구사항을 작성합니다. 설계 에이전트는 초안만 작성하며, 소스 구현은 최신 설계를 게시하고 사용자가 macOS 본인 인증으로 승인한 뒤 시작합니다.

Git이 없으면 Xcode Command Line Tools를 설치하세요. Docker Desktop은 사용자가 설치·실행하고 필요한 권한/약관을 확인합니다. 새 전용 DB는 무작위 자격 증명과 loopback 동적 포트를 사용합니다. 자격 증명은 macOS safeStorage로 암호화되며 renderer에는 전달하지 않습니다.

## 기존 환경과 데이터 이전

기존 개발 DB에 연결되면 원래 환경을 유지합니다. 시작 가이드의 **백업 후 전용 DB로 이전**으로 현재 소유자 워크스페이스를 새 전용 DB에 복원할 수 있습니다. 진행 중/종료 미확인 실행이 있으면 이전하지 않습니다. workspace·이벤트·명령 기록을 백업하고 원본/복원 해시가 일치할 때만 연결을 전환합니다. 원본 DB와 백업/실패한 후보 자원은 자동 삭제하지 않습니다.

자동 이전은 현재 워크스페이스만 대상으로 하며 전체 PostgreSQL 서버의 다른 DB/역할/별도 개발 미리보기까지 옮기지 않습니다. 최대 50 MB, 이벤트·명령 각각 10,000개까지입니다. 더 큰 데이터는 운영자가 백업/이전해야 합니다. API key는 동일 Mac의 원래 vault에 유지되며 다른 Mac에는 다시 입력합니다.

## 복구와 업데이트

- 앱을 닫았다 다시 열면 온보딩 진행과 저장한 비밀이 아닌 입력을 복원합니다. API key 입력 중인 값은 디스크에 저장하지 않습니다.
- Docker가 중단되면 먼저 Docker를 다시 실행하고 시작 가이드의 환경 준비를 다시 누릅니다. 기존 전용 DB를 재사용합니다.
- 준비 중단은 작업을 멈추되 DB 볼륨을 지우지 않습니다. 실패한 단계의 안내를 확인하고 재시도하세요.
- 앱의 일반 종료는 agent 작업을 중단하고 컨테이너 종료를 확인합니다. 강제 종료/절전 후에는 보존된 실행 상태를 확인하세요.
- 업데이트 전 진행 중인 작업의 종료를 확인하고 DB/앱 데이터 폴더를 백업하세요. 자동 업데이트 서버는 제공하지 않습니다.
- 이전 실패 시 원본 DB와 후보 DB를 직접 삭제하지 말고 연결 상태를 확인하세요. 이전 중 저장된 백업은 사용자 데이터의 private/migration-* 아래에 보존됩니다.

실제 provider/tool/streaming, 본인 인증 성공·취소, 서명 변경 후 Keychain, 별도 Mac의 설치 검증을 완료하기 전에는 공개 배포 검증 완료로 판단하지 않습니다. Docker/DB 테스트에서 사용한 fixture CLI는 실제 모델 성공 근거가 아닙니다. 이 앱은 현재 팀 서버/SSO가 아닌 로컬 소유자용입니다.
