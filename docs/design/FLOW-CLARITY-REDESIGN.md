# 개발 흐름 가독성 재설계

## 결정된 문제와 목표

현재 화면은 한 기능을 보는 동안 전역 메뉴, 프로젝트 트리, 다섯 단계, 네 개의 탭, 승인 패널을 동시에 보여 준다. 정보는 충분하지만 무엇을 먼저 봐야 하는지 판단하는 비용이 크다.

이번 변경의 목표는 사용자가 화면을 연 뒤 약 3초 안에 다음 세 가지를 답할 수 있게 하는 것이다.

1. 내가 지금 결정할 일은 무엇인가?
2. 에이전트는 어디에서 무엇을 하고 있는가?
3. 다음으로 열어야 할 작업은 무엇인가?

기존 승인, 실행, 검증, 관제, 하네스 기능과 저장 계약은 유지한다. 이번 변경은 일상 작업의 정보 구조와 표현 순서를 바꾸는 범위다.

## 새 정보 구조

### 전역 탐색

- **홈**: 판단이 필요한 작업, 진행 중인 에이전트, 모든 프로젝트의 흐름
- **작업**: 전체 기능 목록과 단계 보드
- **에이전트**: 실행 중이거나 완료된 실행 기록
- **프로젝트**: 프로젝트별 기능 접근
- **설정**: 하네스, 에이전트, 연결, 지침

전역 관제는 홈의 `전체 관제`와 명령 팔레트에서 연다. 차단 작업은 홈의 `내 결정`에 포함한다. 일상 탐색에서는 같은 데이터를 가리키는 메뉴를 반복하지 않는다.

### 홈

```text
오늘의 개발 흐름                                      새 기능
3개 프로젝트 · 내 결정 2개 · 에이전트 작업 4개

지금 볼 것                         에이전트 작업
승인/수정/실패 행                   현재 작업 행

프로젝트 흐름                                      전체 관제
프로젝트 A  기능 1   계획 ━━━ 개발 ━━━ 검토
              기능 2   계획 ━━━ 개발 ━━━ 검토
프로젝트 B  기능 3   계획 ━━━ 개발 ━━━ 검토
```

수치 카드나 장식용 차트 대신 실제 작업 행을 보여 준다. 사용자는 행을 누르면 필요한 문맥으로 바로 이동한다.

### 기능 상세

```text
프로젝트 / 기능 유형                                현재 상태
기능 이름
요구사항 한 줄

계획 ━━━━━━━━━ 개발 ━━━━━━━━━ 검토        다음 행동 →
요구사항·설계      구현·수정          검증·결과

계획 | 요구사항 편집 | 개발·검증 | 규칙
```

내부의 다섯 단계는 그대로 유지하되 사용자에게는 `계획`, `개발`, `검토` 세 구간으로 묶어 보여 준다. 현재 세부 상태는 단계 아래 한 줄로 표시한다.

## 시각 체계

- 색상: graphite 배경 `#15181d`, surface `#1c2026`, separator `#343c46`, signal blue `#91b8f5`, success `#7ac5a9`, attention `#e2ba7f`
- 글꼴: 시스템 UI는 Apple system/SF 계열, 로그와 식별자는 SF Mono 계열
- 간격: 4, 8, 12, 16, 24px 척도
- 표면: 큰 카드 격자를 만들지 않고 배경, 얇은 구분선, 정렬로 계층을 만든다.
- 핵심 시각 요소: 홈과 기능 상세에서 같은 모양으로 이어지는 3구간 흐름선
- 상태색: 실행, 성공, 주의, 실패의 의미에만 사용한다.

## 상호작용 원칙

1. 행동 우선: 상태 설명 옆에 사용자가 취할 다음 행동을 둔다.
2. 점진적 공개: 정책, 하네스, 전역 관제는 필요할 때 연다.
3. 같은 언어: 내 판단, 에이전트 작업, 시스템 확인을 모든 화면에서 같은 표현으로 쓴다.
4. 직접 이동: 홈의 각 행은 설계 또는 실행 문맥으로 바로 이동한다.
5. 키보드: `⌘1 홈`, `⌘2 작업`, `⌘3 에이전트`, `⌘K 검색`을 유지한다.

## 자체 디자인 검토

- 일반 SaaS 대시보드처럼 통계 카드와 위젯 격자를 늘리지 않는다.
- 기존의 절제된 graphite 체계를 유지하고 흐름선 하나만 제품 고유 요소로 강화한다.
- 정보를 숨겨 단순해 보이게 만들지 않는다. 일상 메뉴에서 제외된 관제와 정책은 홈, 명령 팔레트, 설정에서 계속 접근할 수 있다.
- 다크 모드뿐 아니라 라이트 모드, 1024px 폭, 키보드 포커스, WCAG 자동 검사까지 확인한다.

## 완료 조건

- 처음 진입하면 홈이 열린다.
- 주요 탐색이 홈, 작업, 에이전트로 이해된다.
- 홈에서 내 결정, 에이전트 작업, 프로젝트 흐름을 볼 수 있다.
- 기능 화면의 대표 흐름이 계획, 개발, 검토 세 구간으로 보인다.
- 기존 설계 승인, 실행, 결과 검토, 규칙 접근 기능이 유지된다.
- 브라우저 시나리오, 접근성 검사, 타입 검사, 빌드가 통과한다.
- 다크/라이트 실제 화면을 캡처해 밀도와 계층을 재검토한다.
