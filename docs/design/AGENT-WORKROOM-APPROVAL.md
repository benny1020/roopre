# 선택형 에이전트 작업실 승인

승인일: 2026-09-28.

사용자는 사진처럼 에이전트들이 보이는 UI를 검토해 달라고 요청했다. 작은 아바타와 작업석을 단계별로 묶고 실제 실행 상태·상세 패널로 연결하는 선택형 작업실 제안 후 다음과 같이 지시했다.

> 고고 에이전트한테 별도로 말도 걸 수있으면 좋겠어
>
> 아 그리고 에이전트별로 기억 잘 유지되도록 해야해
>
> 기억관련해서 어떻게 할지리서치하고 설계해서 개발까지해

`고고`는 앞서 제시한 **선택형 작업실 보기**의 구현 승인으로 기록한다. 기존 전역 관제의 프로젝트 흐름·역할 맵·상태 projection·실행 정체성을 유지하고, 실제 실행 인스턴스만 작업석으로 표현한다. 동작 중·오래된 기록·중단 처리 중·종료 후 잔여 기록은 같은 상태로 꾸미지 않는다. 보기·선택·상세 복귀·키보드 포커스를 보존하고 다크/라이트·좁은 창·접근성·실제 Electron을 검사한다.

별도로 요청된 개별 대화·기억은 [세부 설계](AGENT-CONVERSATION-MEMORY.md)의 사용자 검토 대상이다. 이 기록을 새 저장소·provider 호출·실행 입력 변경의 개인 설계 승인으로 사용하지 않는다. 해당 구현은 사용자의 세부 설계 답변 이후 진행한다.

설계·독립 리뷰는 Astra, 제품 구현·수정·검사는 GPT-5.6 Terra가 담당한다. PR은 고정 head/base의 별도 리뷰, 필수 검사와 최신 CI를 확인한 뒤 기존 사용자 위임 `머지는 너가 승인하면 알아서 머지해`에 따라 반영한다. 제품 내부의 본인 설계 승인·macOS 인증 증명을 합성하거나 해제하지 않는다.
