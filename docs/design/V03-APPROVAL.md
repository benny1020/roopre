# v0.3 구현·리뷰·main 반영 승인

2026-09-18 사용자가 Orca 온보딩 보완안을 확인한 뒤 **“옹개발하고 리뷰하고 메인바로반영해”**라고 지시했다. 이 지시는 `HARNESS-V03.md`, `EXTERNAL-BETA-DESIGN.md`, `ORCA-ONBOARDING-PROPOSAL.md`에 제안한 온보딩·환경 준비·단계별 커스텀 에이전트 구현과 전담 리뷰/필수 검사 통과 후 main 반영의 승인으로 기록한다.

이번 저장소 변경의 main 반영 지시는 제품 안에서 미래의 기능 설계를 AI가 대신 승인하거나 자동 머지하도록 변경하는 승인이 아니다. 사용자 데이터 삭제, 공개 Release 게시, 유료 모델 호출, Apple 인증서 구매, 팀 서비스/SSO 확대를 포함하지 않는다. 실제 외부 통합에 필요한 자격 증명과 별도 Mac 검증은 미수행이면 그대로 표시한다.

이번 반영에는 대화에서 명시한 머지 지시를 사용하며 동일 승인을 다시 묻지 않는다. 정확한 최종 head/base의 전담 리뷰와 필수 검사를 확인하고 head 일치 일반 squash merge를 수행한다. admin 우회·강제 push·자동 머지 예약은 사용하지 않는다. 제품의 macOS 본인 설계 승인 경계와 기존 머지 명령은 유지한다.
