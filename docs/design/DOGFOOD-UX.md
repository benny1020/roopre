# 실제 사용을 위한 흐름 개선

2026-09-22. 사용자의 “완벽하게해 바로 쓸수잇도록 너도 이 툴 써서 개발해보고 사용성개선해” 요청 범위다. 기존 사람의 설계 승인, 단계 실행·검증 규칙은 유지한다.

## 발견과 결정

- 실행 화면은 기능의 단계 표시, 실행 선택, 실행 상태, 하네스 설명, 그래프 설명이 누적돼 핵심 작업을 아래로 밀었다. 실행 화면에서는 중복 단계를 줄이고 상태는 실행 선택, 시도는 바로 옆에 표시한다. 과거 실행 표시를 보존한다.
- 그래프 선택 결과가 화면 아래로 밀려 선택과 확인이 분리됐다. 넓은 창은 그래프와 결과·지침 inspector를 나란히 배치하고, 최소 크기 창은 세로로 전환한다. 실제 tree 식별자는 펼쳐서 확인한다.
- 에이전트 추가를 발견하려면 단계 제목을 누른 뒤 별도 설정 영역을 찾아야 했다. 각 단계에 직접 추가 버튼을 두고 키보드 사용과 포커스 복귀도 제공한다. 검색 결과가 없으면 이유와 다음 행동을 표시한다.
- 노드가 많으면 전체 맞춤 때문에 글자가 작아졌다. 처음에는 원래 크기로 표시하고 폭에 맞춰 열을 배치한다. 긴 흐름은 스크롤하며 확대·축소는 사용자가 선택한다.
- 승인·검증 조건의 설명에서 해당 화면으로 이동할 방법이 부족했다. 설계 검토와 현재 시도 검증 결과로 직접 이동한다. 버튼 클릭만으로 승인하거나 실행하지 않는다.

## 확인 기준

단계 추가 버튼의 클릭/Enter/Space, 검색 없음/취소/포커스 복귀, 이동·되돌리기·초안 복원, 실행 잠금, 선택과 현재 작업 구분, 과거 시도 분리, 결과 탐색, 1440×940 및 1024×700, 다크/라이트, axe, 실제 renderer/PostgreSQL 흐름과 Electron 패키징을 확인한다.

## 실제 사용의 경계

이번 확인 시작 시 Mac 잠금으로 사용자 앱 직접 조작이 막혔고 앱에 저장된 AI 연결은 0개였다. 잠금 해제와 앱 내 연결 등록을 요청했다. 실제 모델 구현 실행 및 사용자 본인 설계 승인에 대한 완료 증거가 생기기 전에는 이를 dogfooding 성공으로 보고하지 않는다. 격리된 회귀 시나리오와 실제 사용자 환경을 구분해 최종 검증 기록에 남긴다.
