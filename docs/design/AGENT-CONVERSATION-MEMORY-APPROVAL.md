범위는 프로젝트·에이전트·기능별 읽기 전용 상담, 원문과 자동 요약의 영속 저장, 사용자 확정 작업 기억, 승인 바인딩과 실행 입력의 기억 스냅샷, 삭제·중단·재시작·DB 이전, 맥락 UI와 설계에 명시된 검증이다. 실행 중인 CLI에 실시간 지시 주입은 포함하지 않는다. 제품 내부의 다른 설계 승인과 본인 인증을 대신하지 않는다.

Astra가 설계·독립 리뷰, GPT-5.6 Terra가 구현·검사·수정을 담당한다. 저장·상담, 기억·실행 계약, UI를 파일 소유권이 겹치지 않게 병렬 진행하며 계약은 공유한다. 독립 exact-head 리뷰·CI·게시 검사 후 기존 사용자 위임 `머지는 너가 승인하면 알아서 머지해`에 따라 main에 반영한다.

실제 모델 호출·사용자 본인 인증·장기 운영·App Store 제출 적합성은 fixture나 패키지 검사와 구분해 보고한다.
