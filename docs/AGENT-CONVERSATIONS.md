# 에이전트 상담과 작업 기억

이 안내는 [승인된 개별 대화·기억 설계](design/AGENT-CONVERSATION-MEMORY.md)의 사용 흐름을 설명한다. 실제 검증 완료 범위는 [구현 기록](design/AGENT-CONVERSATION-MEMORY-IMPLEMENTATION.md)과 [검증 문서](VERIFICATION.md)를 따른다.

## 에이전트에게 질문하기

전역 관제에서 프로젝트와 기능을 선택하고 배치된 에이전트 또는 실행 기록을 연다. Inspector의 **작업 / 대화 / 기억**으로 현재 작업, 별도 상담, 확정한 참고 기록을 전환한다. 에이전트가 아직 실행되지 않아도 배치된 역할을 선택해 질문할 수 있다.

대화는 선택한 프로젝트·에이전트·기능에 속한다. 프로젝트 공통 상담은 기능 상담과 별도의 기록이다. 같은 전역 에이전트를 여러 프로젝트에 배치해도 프로젝트 사이에 대화와 기억을 공유하지 않는다.

상담에는 에이전트의 현재 정의와 지침, 선택한 범위의 기록이 사용된다. 과거 실행을 선택한 경우 실행 당시의 기록을 참고하되 상담 연결과 에이전트 정의는 현재 설정을 따른다. 답변의 맥락 표시에서 실제 사용한 기억과 대화 출처를 확인한다.

상담은 실행 중인 Claude Code에 직접 끼어드는 기능이 아니다. 질문으로 코드 변경·실행 취소·승인·머지를 수행하지 않는다. 구현 변경은 요구사항과 설계에 반영한 뒤 기존 승인 흐름으로 진행한다.

## 답변을 다음 작업의 기억으로 남기기

1. 유용한 답변에서 **기억으로 저장**을 선택한다.
2. 다음 작업에 필요한 제목과 내용을 직접 검토한다. 답변 전체를 그대로 보존할 필요는 없다.
3. 해당 기능에만 적용할지 프로젝트 전체에 적용할지 선택한다. 기능에서 나온 내용을 프로젝트 공통으로 승격할 때는 적용 범위를 명시적으로 확인한다.
4. 저장 후 **기억**에서 내용·출처·버전을 확인한다. 오래되거나 틀린 기록은 수정하거나 비활성화한다.

대화 원문, 자동 요약, 사람이 확인한 작업 기억은 서로 다르다. 자동 요약은 상담 편의를 위한 미검증 정보이며 자동으로 작업 기억이 되지 않는다. 기억은 정책이나 승인 증명을 대신하지 않는다.

기억 변경은 다음 실행의 입력을 바꾸므로 해당 프로젝트의 기존 설계 승인에 영향을 준다. 대기·실행 중이거나 종료가 확인되지 않은 작업이 있으면 먼저 종료해야 한다. 실행을 시작할 때 기억의 내용·버전·해시를 고정하므로 진행 중인 실행의 입력이 뒤에서 바뀌지 않는다.

## 실패와 보관

요청 실패나 앱 재시작 후 상담을 자동 재전송하지 않는다. 실패 상태와 입력을 확인한 뒤 직접 재시도한다. 재시도는 새 모델 요청이므로 비용이 발생할 수 있다. 기록된 토큰 사용량은 provider가 보고한 값이며 임의 endpoint의 실제 청구액을 의미하지 않는다.

대화를 삭제할 때 그 대화에서 만든 기억 중 비활성화할 항목을 선택한다. 원문 삭제와 선택한 기억 변경은 함께 처리한다. 원문을 삭제하고 기억을 남기면 기억의 출처 ID는 남지만 삭제한 대화 내용은 다시 열 수 없다.

원문과 요약은 PostgreSQL에, 모델 연결 비밀은 기존 macOS 암호화 연결 저장소에 보관한다. 상담 시 선택된 기록은 사용자가 설정한 HTTPS endpoint로 전송된다. Harness 내보내기에는 개인 대화와 작업 기억을 포함하지 않는다. DB 이전은 이를 보존하므로 이전 백업 파일도 개인 작업 기록으로 취급한다.

## 현재 한도와 검증 경계

- 활성 작업 기억: 에이전트별 20개, 제목·본문 합계 12,000자. 개별 본문은 2,000자.
- 상담: 한 대화에 한 요청, 앱 전체 두 요청까지. 질문은 8,000자, 모델 응답 제한은 4,096토큰.
- 원문 저장: 대화별 5MiB, 워크스페이스별 100MiB. 한도 초과 시 기존 내용을 조용히 지우지 않고 요청을 거절한다.
- 자동 DB 이전: 전체 백업 50MB 및 기록 수 제한이 따로 적용된다. 저장 한도 안이어도 자동 이전 한도를 초과할 수 있다.
- 연결: 기존 Anthropic Messages 호환 endpoint를 사용한다. OpenAI API 규격이나 임의 CLI 세션 재개를 추가한 기능은 아니다.

테스트용 provider를 사용한 Electron·DB·Docker 검증과 실제 유료 모델의 답변 품질·연결 호환성은 별도다. 공개 배포·공증·App Store 심사 완료를 의미하지 않는다.
